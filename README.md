# ELEC-D1320: Automated Sauna Water Heater Assembly Simulation

A collaborative Visual Components project modeling an automated assembly cell for a sauna water heater. The coursework was carried out in Aalto University's Win 3D environment.

## My contribution

I was responsible for the project work other than welding, including modeling, robot-arm communication, and programming.

## Team contribution

Joris handled the welding work, recorded the simulation video, and helped proofread and correct my part.

## Tools and context

- Course: ELEC-D1320, Aalto University
- Environment: Aalto Win 3D
- Simulation software: Visual Components; the archived model metadata identifies version 4.9.2.25

## Published materials

This portfolio entry describes the project and team contributions. The Visual Components model and recorded demonstration are omitted because the model bundles eCatalog and vendor assets, and permission to redistribute those assets publicly has not been established. The source files are retained in the project's private repository.
